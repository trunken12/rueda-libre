## ¿Qué es esto?
Sitio web estático de **Rueda Libre**, un taller con alquiler de bicicletas eléctricas en Getafe. Lo construye el equipo **NOMBRE DEL EQUIPO** como proyecto del curso IFCD0210, unidad formativa UF1841.

**Pregunta que resuelve la web:** ¿cómo hacemos que cualquier persona, desde cualquier dispositivo, entienda los servicios de Rueda Libre y reserve una cita sin ayuda?

## Ver la web
- Publicada: ENLACE DE GITHUB PAGES (se rellena en la sesión 11)
- En local: abre la carpeta con VS Code y pulsa **Go Live** (extensión Live Server).

## Cómo colaboramos
1. Cada tarea es una *incidencia* (issue) del tablero.
2. Se trabaja en una rama con el nombre de la tarea.
3. Se abre una *pull request*; otra persona del equipo la revisa antes de fusionarla (desde el sprint 2).
4. Se cumple la **definición de hecho** (`DEFINICION_DE_HECHO.md`).
