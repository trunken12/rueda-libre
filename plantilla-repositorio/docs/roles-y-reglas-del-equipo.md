# Roles y reglas del equipo

## Roles (rotan en cada sprint)
| Rol | Qué hace | Sprint 1 | Sprint 2 | Sprint 3 |
|---|---|---|---|---|
| Facilitador | Dirige la reunión diaria de 15 min y mantiene el tablero | | | |
| Responsable de calidad | Valida el código y lanza las auditorías | | | |
| Responsable de repositorio | Guarda las versiones y, desde el sprint 2, revisa las pull requests | | | |

## Reunión diaria (15 min, de pie)
1. ¿Qué hice ayer / en la sesión anterior?
2. ¿Qué haré hoy?
3. ¿Qué me bloquea?

## Reglas
- Nadie trabaja directamente sobre `main`.
- Un *commit* = un cambio pequeño con un mensaje que lo explica («Añade la tabla de tarifas»).
- Si algo se atasca más de 10 minutos, se pregunta a la pareja de apoyo y después al docente.
