# Definición de hecho

Una tarea o página está **hecha** solo cuando cumple *todos* los puntos de su sprint. Se amplía en cada sprint.

## Sprint 1 (guiado)
- [ ] El HTML **valida sin errores** en el validador del W3C (validator.w3.org).
- [ ] El código está **comentado** (cabecera de la página y partes no evidentes).
- [ ] Cada página tiene `lang`, codificación UTF-8, título único y estructura semántica (`header`, `nav`, `main`, `footer`).
- [ ] Los enlaces entre las páginas funcionan (un compañero los ha probado).

## Sprint 2 (se suma a lo anterior)
- [ ] Todo el sitio se **recorre con el teclado** (Tab, Mayús+Tab y Enter).
- [ ] Otra persona del equipo ha **revisado el cambio en una pull request**.
- [ ] Tablas con `caption`, `thead` y `scope`; formulario con `label`, validación y `fieldset`.

## Sprint 3 (se suma a lo anterior)
- [ ] Se ve bien **en móvil** y **en dos navegadores**.
- [ ] El contraste de color cumple 4,5 : 1 (texto normal).
- [ ] La auditoría (Lighthouse, axe y teclado) no tiene fallos críticos.
- [ ] El sitio está **desplegado** en GitHub Pages y el README está completo.
